# Supplement Retail Demand Forecasting & Inventory Planning

Weekly SKU-level demand forecasting with an inventory-planning layer
(safety stock, reorder point, EOQ, stockout risk), deployed as a Streamlit app.
Code is the production version of the NIT Calicut project notebook.

## Structure

```
supplement_forecast/
├── data/supplement_sales.csv   # raw input (you add this)
├── artifacts/artifacts.pkl     # generated by train_pipeline.py
├── preprocessing.py            # cleaning + calendar/lag/rolling features
├── train_pipeline.py           # walk-forward CV (ETS, Prophet, pooled XGBoost) + forecasts
├── planning.py                 # ROP / safety stock / EOQ / stockout probability / simulation
├── app.py                      # Streamlit app: Overview / Forecast / Planning
├── requirements.txt
└── Dockerfile
```

## Run locally

```bash
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
# put the CSV at data/supplement_sales.csv
python train_pipeline.py        # builds data/processed.csv + artifacts/artifacts.pkl
streamlit run app.py
```

Re-run `python train_pipeline.py` whenever new weekly data is appended; the app
only loads saved artifacts, it never trains live.

## Deploy on Streamlit Community Cloud (free)

1. Push this folder to a GitHub repo **including** `data/processed.csv` and
   `artifacts/artifacts.pkl` (run the training step locally first).
2. Go to share.streamlit.io -> New app -> pick the repo -> main file `app.py`.
3. Python 3.11 is recommended (Advanced settings) - Prophet installs most reliably there.

## Deploy with Docker

```bash
docker build -t supplement-forecast .
docker run -p 8501:8501 supplement-forecast
```

## Method summary

- Models per product: ETS (Holt-Winters, period 52), Prophet (Price/Discount regressors),
  pooled XGBoost (recursive multi-step forecast).
- Selection: 3-fold expanding-window walk-forward CV, 8-week horizon, lowest MAPE wins per product.
- Planning: safety stock = z x sigma x sqrt(L); ROP = demand x L + safety stock;
  EOQ from ASP as cost proxy; stockout probability under Normal lead-time demand.
  Lead time, service level, inventory, ordering and holding cost are user inputs.
